개인정보 처리방침

최종 업데이트: 2026-07-11

Life Reminder는 회원가입·로그인이 없고, 사용자를 식별하는 어떠한 정보도 수집하지 않습니다.

기기에 로컬로 저장되는 정보

  • 등록한 물건의 사진(썸네일), 이름, 등록 일시, 메모, 교체 주기
  • 알림 시간대, 알림 단계별 on/off 등 설정값

위 정보는 기기 내부 저장소(AsyncStorage)에만 저장되며, 사용자 계정이나 클라우드 동기화 없이 오직 이 기기에서만 관리됩니다. 앱을 삭제하면 모두 삭제됩니다.

외부로 전송되는 정보

  • 물건 자동 인식 시 — 카메라로 찍거나 갤러리에서 선택한 사진이, 앱 서버(Supabase Edge Function)를 거쳐 Google Cloud Vision API로 전송되어 사진 속 물건의 라벨을 인식하는 데에만 사용됩니다. 사진은 인식 처리 목적으로만 사용되며 서버에 저장되지 않고 즉시 폐기됩니다.
  • 내장 목록에 없는 물건일 경우 — 사진이 아닌 인식된 텍스트 라벨만 Groq API로 전송되어 교체 주기와 설명 문구를 생성하는 데 사용됩니다.
  • 피드백 전송 시에만 — 설정 → 피드백에서 사용자가 직접 작성하고 전송을 누른 내용(과 앱 버전)만 개발자에게 전달됩니다.

위 세 가지 경우를 제외하고는 어떠한 정보도 외부로 전송되지 않으며, 등록한 물건 목록 자체가 서버에 저장되거나 다른 목적으로 활용되는 일은 없습니다.

권한 사용

  • 카메라 / 사진 보관함 — 물건 사진을 촬영하거나 선택하기 위해서만 사용합니다.
  • 알림(Notification) — 설정한 시간에 교체 시기를 알려주기 위해서만 사용하며, 기기 내에서 예약·처리됩니다.

제3자 서비스

광고, 분석(analytics), 크래시 리포팅 SDK를 포함하지 않으며 사용자 행동을 추적하지 않습니다. 위에 명시한 Google Cloud Vision, Groq(물건 인식·문구 생성), 피드백 전달을 위한 서버 통신만 존재합니다.

문의

개인정보 처리방침에 대한 문의는 앱 내 설정 → 피드백을 통해 연락해주세요.

Privacy Policy

Last updated: 2026-07-11

Life Reminder has no sign-up or login, and does not collect any information that identifies you.

Information Stored Locally on Your Device

  • Photos (thumbnails), names, registration dates, notes, and replacement cycles of the items you register
  • Settings such as notification time and which reminder stages are enabled

This data is stored only in on-device storage (AsyncStorage), with no account or cloud sync — it is managed on this device alone. Deleting the app removes this data.

Information Sent Externally

  • When recognizing an item — a photo you take or pick is sent, via our server (a Supabase Edge Function), to the Google Cloud Vision API solely to detect labels in the photo. The photo is used only for this recognition and is not stored server-side; it is discarded immediately after processing.
  • For items not in our built-in list — only the recognized text labels (not the photo itself) are sent to the Groq API to generate a suggested replacement cycle and description.
  • Only when you send feedback — the message you write in Settings → Feedback (and your app version) is delivered to the developer.

Outside of these three cases, no information is sent anywhere, and your registered item list itself is never stored on a server or used for any other purpose.

Permissions

  • Camera / Photo Library — used only to take or select a photo of an item.
  • Notifications — used only to remind you when it's time to replace an item; scheduled and handled entirely on-device.

Third-Party Services

This app includes no advertising, analytics, or crash-reporting SDKs, and does not track user behavior. The only network calls are the Google Cloud Vision and Groq calls described above (for item recognition) and the feedback delivery.

Contact

For questions about this policy, reach out via Settings → Feedback in the app.
